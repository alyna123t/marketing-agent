# Audiences — Simmer

*Read by every `format-*` skill. Each draft must pick exactly ONE of these before
drafting (the folded-in "audience angle" step). Mixed-audience drafts are rejected.*

## The four audiences

### Trader
- **Wants:** edge, real results, what actually made/lost money.
- **Write:** aggregate PnL, win/loss mix, what a strategy did and why. Losses build trust.
- **Avoid:** build/implementation detail, founder philosophy.

### Builder / developer
- **Wants:** how it works, can I reproduce it, what's the SDK/skill.
- **Write:** implementation path, reproducible result, "how we did X."
- **Avoid:** vague hype, results with no method.

### Founder / operator
- **Wants:** the model — how one person + agents runs a real company.
- **Write:** the system, the trade-offs, the honest scars.
- **Avoid:** low-level trading mechanics.

### Partner
- **Wants:** credibility, traction, why Simmer is worth integrating with.
- **Write:** aggregate proof, reliability, scale signals. Highest scrutiny — usually Tier 3.
- **Avoid:** anything forward-looking or unverified.

## Rule
One post, one audience. If an angle serves two audiences, it's two posts (re-argued),
not one blended post. This is a per-draft checklist item, not a separate skill.
